# NF-MLP 当前实验总结

本目录总结截至 2026-08-31 的神经场替换 MLP 非线性实验。核心约束是保持前后线性层不变：

```text
W_up:   784 -> 64
NF:      64 -> 64
W_down:  64 -> 10
```

实验使用 MNIST 前 5000 个训练样本、batch=128、seed=0，除特别说明外训练 10 轮。测试集准确率仅用于实验结束后的评估，不参与训练参数选择。

## 当前基线

最好的 NF 基线是矩形神经场三方向版本：

```text
route=all
H=64, W=16
T 初始值=0.5
G 初始值=1.0，逐神经元可学习
主学习率=0.003
残差 alpha=1.0
输入倍率=3.0
线性能量传递
```

10 轮最高准确率约 **90.40%**。同一数据规模下，64 隐藏单元 ReLU MLP 20 轮最高约 **92.84%**，普通 CNN 5 轮约 **93.85%**。

## 阈值实验

固定三方向、G 可学习且 G lr=0.0001，只改变初始阈值：

| T | 最高准确率 |
|---:|---:|
| 0.30 | 90.32% |
| 0.40 | 89.94% |
| 0.50 | 90.33% |
| 0.60 | 89.71% |

阈值过高会减少末端传播，阈值过低会引入更多噪声；目前合理范围约为 0.3～0.5。

## 当前实现认识

早期路由版本是发送端硬选择方向，容易丢失分支。并行版本让允许方向同时传播，准确率从约 90.13% 提高到 90.67%，说明保留传播分支是有价值的。

随后测试了接收端融合：目标神经元同时接收左上、左、左下，再学习来源重要性。它能够保持约 90.6%，但固定接收权重仍然不能根据不同样本动态判断来源。

能量驱动权重版本只根据当前能量大小判断重要性，导致激活率接近 95%，强能量和汇聚噪声被一起放大，最高约 90.10%。这表明“能量越大越重要”并不是足够的逻辑。

扩大到五点或整列接收没有提高准确率，整列全接收明显退化，说明小数据集下直接增加感受范围和自由度会导致不稳定或过拟合。

## 关键问题

当前 NF 的主要差距不是单个超参数，而是传播单元仍然缺少输入相关的特征判断：

```text
当前：能量被门控、搬运、加权
缺少：根据当前局部组合判断哪些信息值得保留
```

同时，残差连接允许模型绕过 NF，因此分类交叉熵并不要求场内传播本身稳定或有意义。`T/G/Q` 即使有梯度，也可能只是在帮助分类路径抑制噪声，而不是形成可解释的传播逻辑。

## 当前建议方向

在保持 `784->64->10` 不变的前提下，下一步应优先研究低参数量的输入依赖接收机制：

1. 所有候选来源同时到达目标神经元；
2. 使用共享的小型能量/状态评价函数判断来源可靠性；
3. 权重同时考虑当前能量、符号、邻域一致性和连续传播稳定性；
4. 保留阈值截断，但避免独立的方向参数、增益参数和复杂列属性全部自由学习；
5. 逐步增加机制，每次只引入一个新自由度。

## 运行方式

```powershell
py -3 train_mnist.py --model rect_nf --epochs 10 --lr .003 --subset 5000
py -3 tests\test_field.py
```

并行传播示例：

```powershell
py -3 train_mnist.py --model rect_nf --rect-route parallel_ru --rect-threshold .5 --rect-gain-lr .0001 --epochs 10 --lr .003 --subset 5000
```

HTML 模拟器可以直接双击 `tools/energy_propagation_simulator.html`，观察阈值、增益、传播方向和逐列能量变化。
