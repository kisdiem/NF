# 设计说明

## A. Dynamic NF

```text
784 → Linear(64) → [B,16,4]
                         ↓
              Q/K → G[B,16,16]
                         ↓
              message = GᵀH
                         ↓
              local branch + gated residual
                         ↓
              flatten → Linear(10)
```

它允许双向和循环关系，但每一步都需要全局节点关系，复杂度包含 O(N²)。

## B. BioNeuron

```text
多个突触输入
 → 多个树突分支局部组合
 → 兴奋/抑制竞争
 → 膜电位 V
 → 动态阈值 theta
 → surrogate spike
 → 下一时间步状态
```

用于研究局部非线性、时间积累和适应机制；第一阶段不包含 Hodgkin-Huxley、STDP 或复杂离子通道。

## C. Local Electrical NF v1

输入经过 `Linear(784,64)` 后 reshape：

```text
[B,784] → [B,1,8,8]
```

每个节点有独立的 `threshold`、`strength` 和 `decay`；v1 还使用了 excitatory/inhibitory sign。传播 kernel：

```text
0.7  1.0  0.7
1.0  0.0  1.0
0.7  1.0  0.7
```

更新：

```text
gate = sigmoid((V-T)/tau)
release = gate × signed_strength
incoming = conv2d(release, local_kernel)
V_next = decay × V + incoming
```

## D. Local Electrical NF v2

删除固定 sign，基础 release 全部为正，并根据邻域活动产生动态抑制：

```text
E = conv2d(release, K_E)
A = conv2d(release, K_I)
gI = sigmoid((A-rho)/tau_I)
I = beta × gI × A
V_next = decay × V + E - I
```

refractory 是独立 variant：

```text
R_next = lambda_R × R + release_gate
theta_eff = theta + gamma × R
```

## E. v3/v4 稳定化

测试了 excitation kernel 归一化、增大 beta、增强 leakage、空间中心化、软复位和有界净输入。

当前最有效的稳定方案 `raw_bounded`：

```text
incoming = tanh(excitation - inhibition)
V_next = decay × V + incoming
```

另有 `raw_unbounded` 对照：保留原始局部传播，不使用净输入 tanh，也不加入动态 inhibition。它用于区分“能力来自更强传播”还是“稳定限制带来的泛化”。

## F. 并行化

* 空间节点：通过 conv2d 一次并行计算。
* excitation/inhibition：融合为一个 `[2,1,3,3]` 卷积，输出两张局部图。
* 时间步：不能直接并行，因为 `V(t+1)` 依赖 `V(t)`。
* 诊断：推理时可关闭，避免 `.item()` 和热图统计拖慢部署。

Local NF 从不构造 Q/K、attention 或 N×N 关系矩阵。
