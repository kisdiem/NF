# 复现命令

以下命令在项目根目录执行。Windows 环境使用 `py -3`。

## 基础 MNIST

```powershell
py -3 train_dynamic_nf.py --epochs 10 --subset 5000 --models linear,relu,gelu,dynamic --device cpu
```

## Local Electrical NF v1

```powershell
py -3 train_local_electrical_nf.py --epochs 10 --subset 5000 --batch 128 --steps 4 --device cpu
```

## v2 动态抑制

```powershell
py -3 train_local_electrical_nf_v2.py --epochs 20 --subset 5000 --batch 128 --steps 4 --device cpu --result-tag seed0
```

## v3 稳定化筛选

```powershell
py -3 train_local_electrical_nf_v3.py --epochs 20 --subset 5000 --batch 128 --steps 4 --device cpu --result-tag seed0
```

## v4 能量尺度候选

```powershell
py -3 train_local_electrical_nf_v4.py --epochs 20 --subset 5000 --batch 128 --steps 4 --models raw_bounded,raw_strong_bounded --result-tag raw_bounded20 --device cpu
```

## 跨数据集

```powershell
py -3 benchmark_cross_dataset.py --datasets xor,circles,moons,classification10 --n 4000 --epochs 50 --batch 128 --result-tag synthetic_seed0
py -3 benchmark_cross_dataset.py --datasets digits8x8 --n 1797 --epochs 100 --batch 128 --result-tag digits_seed0
```

## 困难任务

```powershell
py -3 benchmark_hard_tasks.py --epochs 100 --n 6000 --batch 128 --seed 0 --result-tag seed0
```

无界对照：

```powershell
py -3 benchmark_hard_tasks.py --tasks checkerboard,noisy_spiral100 --epochs 100 --n 6000 --batch 128 --seed 0 --result-tag unbounded_seed0
```

## 因果诊断

```powershell
py -3 diagnose_local_nf_causality_v2.py --epochs 5 --subset 5000 --batch 128 --device cpu
```

## 推理基准

```powershell
py -3 benchmark_local_nf_inference.py --device cpu --threads 1 --warmup 20 --repeats 500
```

## 依赖

项目主要依赖 PyTorch、torchvision、numpy、scikit-learn 和 matplotlib。MNIST 会由 torchvision 自动下载；如果网络不可用，需要提前把数据放在 `data/mnist`。
