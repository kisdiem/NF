# Local Electrical NF 稳定性实验总结

本轮在不覆盖 v1/v2 结果的前提下，新增 v3/v4 稳定化实验。实验条件均为 MNIST subset=5000、full test=10000、hidden=64、batch=128、seed=0、Adam、20 epochs。

## 已测试的稳定化方法

1. 兴奋 kernel 归一化：状态变化稳定，但信号被缩小约 6.8 倍，准确率降到约 90.9%。
2. 归一化 + 增大 excitation gain：准确率恢复，但需要重新平衡 inhibition 和 decay。
3. 强抑制、增大泄漏：`state_change` 可以下降，但准确率明显损失。
4. refractory：降低连续释放，但准确率下降，不能单独解决正反馈。
5. 空间中心化：减小公共膜电位漂移，但会损失绝对能量信息。
6. 软复位：能抑制累积，但当前固定复位量使训练变难。
7. 原始兴奋尺度 + 净输入 tanh：保留信号幅度，同时限制每一步最大更新，是当前最平衡的方案。

## 关键结果

| 版本 | best test | final test | activation rate | state change | CPU 秒 |
|---|---:|---:|---|---|---:|
| v1 no-inhibition | 93.47% | 93.44% | 0.505 → 0.925 | 0.637 → 1.484 | 181.62 |
| v2 dynamic inhibition | 92.97% | 92.82% | 0.127 → 0.484 | 0.712 → 1.388 | 227.48 |
| v3 normalized | 90.91% | 90.80% | 0.304 → 0.374 | 0.330 → 0.224 | 311.58 |
| v4 full-scale balanced | 93.01% | 91.77% | 0.124 → 0.382 | 0.874 → 0.580 | 330.64 |
| v4 raw-bounded | **93.38%** | 93.19% | 0.107 → 0.349 | 0.542 → 0.584 | 349.03 |
| v4 raw-strong-bounded | 93.32% | 93.24% | 0.122 → 0.368 | 0.651 → 0.537 | 351.98 |

`raw-bounded` 的更新是：保留原始 3×3 兴奋传播量，计算兴奋减抑制后的净输入，再施加 `tanh`，最后与衰减膜电位相加。它不是把状态直接裁剪，而是限制单步净输入，因此仍允许多步传播。

## 阶段性判断

目前不能说“所有简单稳定化机制都能同时解决准确率和动力学问题”。已经验证：

* 固定抑制 sign 确实不是理想方案；
* 动态抑制能降低激活率，但抑制量仍不足以抵消正向累积；
* 单纯归一化会破坏有效表征尺度；
* `raw-bounded` 首次同时取得接近 no-inhibition 的准确率和近似稳定的状态变化，说明“受限的能量预算”比单纯增加 inhibition 更合理；
* 但最高准确率仍低于 no-inhibition 0.09 个百分点，且 state change 仍是平台而非逐步趋零，因此问题尚未完全解决。

下一步若继续，应优先做可学习的能量守恒/归一化增益，以及以每个样本局部活动为条件的抑制，而不是扩大网格或增加传播步数。若这些机制仍不能超过 93.47% 且保持稳定，则应判定当前局部电场方程在 MNIST 上的主要瓶颈是“正向传播导致的有用信号与稳定约束不可兼得”。

## Field 是否真的被模型使用

仅有非零梯度不能证明 field 对性能有实质贡献。为此对 `raw_bounded` 做了 5 轮因果冻结对照：field 仍保留在前向路径，但一组训练 field 参数，另一组冻结 field 参数。可训练组最终 test=91.74%，冻结组为 91.67%，差异仅 0.07 个百分点。

这说明当前模型虽然会给 field 参数传递梯度，但在短期训练中分类器主要依赖输入/输出 Linear 和一个近似固定的正向场变换。后续若要证明 NF 动力学真正有效，需要继续做 field 替换/冻结、状态扰动和 readout 对照，而不能只凭参数梯度或准确率上升下结论。

进一步的因果扰动（5 epochs，subset=5000）显示：正常 field 为 91.74%，打乱 8×8 空间位置后为 9.59%，只保留空间均值为 19.42%，置零 field 为 10.32%，改为 one-step 为 59.94%。因此空间场输出本身确实被 classifier 使用；真正缺少的是“训练后的动态参数相对于初始场变换的额外贡献”。冻结 field 的 91.67% 与可训练 field 的 91.74% 几乎一致，field 参数虽然发生了可测变化并收到梯度，但没有带来明显泛化收益。

## 等价并行化优化

每个时间步的 excitation 和 inhibition 都从同一个 `release` 输入计算，只是使用不同的 3×3 kernel。新增 `fuse_local_convs` 开关后，将两个 kernel 堆成一个 `[2,1,3,3]` 卷积，一次输出两张局部图，再分别取 excitation 与 activity。该优化不改变公式：同一输入、同一 padding、同一浮点结果（实测输出最大差异为 0），只减少卷积调度。

在 CPU、subset=5000、batch=128、5 epochs、raw_bounded 下：原版为 88.47 秒，融合版为 78.03 秒，减少 **11.8%**；训练曲线逐轮完全一致。时间步之间仍不能直接并行，因为 `V(t+1)` 依赖 `V(t)`；但每个时间步内部的节点和局部邻域已经是 GPU/向量化并行。进一步的 `torch.compile`、CUDA/AMP 和 DataLoader 优化属于运行时优化，不改变算法逻辑。

### 推理时间

单独关闭梯度和诊断采集后，在 CPU 单线程、预热 20 次、计时 500 次的基准中：

| batch | ReLU MLP | GELU MLP | Dynamic NF | Local NF 原版 | Local NF 融合版 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.0320 ms | 0.0706 ms | 2.1773 ms | 0.4388 ms | 0.4854 ms |
| 128 | 0.3171 ms | 0.3031 ms | 9.6233 ms | 3.8278 ms | 2.1770 ms |

batch=128 时融合卷积使 Local NF 推理降低 43.1%；batch=1 时由于一次小卷积的 kernel 调度开销，融合版反而慢 10.6%。因此实际部署应根据 batch 选择实现。关闭诊断采集本身也很重要：诊断只用于实验，不应进入生产推理路径。
