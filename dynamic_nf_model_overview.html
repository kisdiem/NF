Dynamic Neural Field

当前实验版本：Linear → 动态关系场 → Linear。它不是原始矩形 NF，也不是 Transformer；它使用同一节点池中的有符号、样本相关、同步动态关系。

1. 总体数据流

输入MNIST [B,784]
→
Input Linear[B,64]
→
Reshape[B,16,4]
→
Dynamic FieldH₀→Hₜ
→
Output Linear[B,10]

64 维隐藏容量被组织成 16 个节点，每个节点 4 维。

2. 节点状态

H_t shape = [batch, 16, 4] 所有节点属于同一个节点池。 每个时间步读取同一个 H_t，统一计算后同步更新。

3. 动态 Router

Q = HₜWq　 K = HₜWk
scoreᵢⱼ = Qᵢ · Kⱼ / √4
Gₜ = tanh(score / temperature) × gain

Gᵢⱼ > 0：促进Gᵢⱼ < 0：抑制

G shape = [batch,16,16]。Gᵢⱼ 表示源节点 i 对目标节点 j 的作用；不做 softmax，不要求对称或归一。

4. 一个时间步：同步消息传递

所有节点先读取 Hₜ 1. 统一生成 Gₜ 2. message = Gₜᵀ @ Hₜ 3. 所有节点同时计算 candidate 4. 所有节点同时门控更新为 Hₜ₊₁ 不会出现 A 更新 B 后，B 在同一步立刻更新 C。
messageⱼ = Σᵢ Gₜ[i,j] × Hₜ[i]

默认允许 A→B，下一步也允许 B→A；这里的反向是前向动力学反馈，不是 backpropagation。

5. 局部多分支非线性

branch_b = tanh(Wself_b(Hⱼ) + Wmsg_b(messageⱼ))
candidateⱼ = Σᵦ αᵦ × branch_b

默认 B=4。树突式分支只负责节点内部局部组合，整体核心仍是动态关系场。

6. 持续状态与稳定化

gate = sigmoid(Wgate[Hⱼ, messageⱼ])
Hₜ₊₁ = (1−gate)Hₜ + gate·candidate

更新后使用 LayerNorm；关系增益初始为 0.1，避免循环反馈一开始过强。

默认 T=4：H₀→G₀→H₁→G₁→H₂→G₂→H₃→G₃→H₄

8. 消融定义

版本改变
Dynamic每步重算关系，4步，状态保留
Fixed relation只算 G₀，后续复用

No feedback关系限制为三角形

版本最高准确率

当前证据尚不支持多步动态关系优于固定关系或单步更新；状态保留是最明确有效的机制。
